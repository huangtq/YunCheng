## 参考站模板归类

模板只保存区块顺序、分区、列数、图片比例和数量限制。每场会议只替换主视觉、入口图、标题、入口目标、主题色和页脚。

| 模板 | 参考站 | 固定结构 |
| --- | --- | --- |
| 图片菜单 | `38736`、`38335`、`30995`、`24669` | 主视觉 → 倒计时 → 两列连续图片入口 → 页脚 |
| 分区图片菜单 | `38760` | 主视觉 → 倒计时 → 快捷入口区 → 重点入口区 → 页脚 |
| 图标导航 | `29690` | 主视觉 → 倒计时 → 三列图标入口 → 页脚 |
| 整图热点海报 | `36428` | 长海报 → 透明矩形热点 |

因此，图片、颜色或入口链接不同，不会新增模板；只有页面区块顺序、分区或卡片比例不同才新增模板。

## 未完成与当前风险

### 1. 将模板能力并入【九宫格配置】（最高优先级）

当前新增了独立路由 `home-composer`，并在九宫格页面放置“整页参考模板”跳转。这只是过渡实现，和已确认的交互不符。

后续应直接改造 `web/src/views/meeting/grid/index.vue`：

1. 保留现有九宫格列表、素材管理和入口编辑能力；
2. 在该页顶部提供模板卡片与参考图；
3. 模板选中后，列表按模板的固定区块展示，而不是跳转新页面；
4. 同页提供主视觉、主题色、倒计时、页脚、分区入口及发布版本操作；
5. `home-composer` 迁为内部复用组件或删除路由，避免两套配置源并存。

完成前，不应把独立“首页编排”入口当作最终运营方案。

### 2. 真实浏览器与接口验收

尚未形成“选择模板 → 配置资源 → 保存草稿 → 发布 → H5 展示”的完整现场证据。下一次验收应以一个专用测试会议完成四类样例：共享图片菜单、分区图片菜单、图标导航、整图热点。

### 3. 图片素材与参考站像素还原

当前模板预览使用外部参考图片 URL，正式产品应上传并引用项目受控素材。页面已经对齐结构与比例，但尚未使用每个参考会议的完整真实图片和入口内容做逐屏比对。

### 4. 发布前配置体验

服务端已校验区块最小/最大入口数、合法目标和热点坐标；后台已增加基础提示。仍需在合并后的九宫格页面补足排序、分区内拖拽、Tile 重叠/越界可视化提示以及发布前差异预览。

### 5. 其他 Phase 验收

内容附件签名下载、模块专用页面深度体验、历史会议迁移演练、权限审计和完整回滚演练仍未完成。阶段状态以 [01-p0-foundation.md](01-p0-foundation.md) 为准。
