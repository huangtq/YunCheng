# Phase 3：P2 体验与运营

## 目标

在 P0 的可配置首页和 P1 的参会服务之上，完善可度量的会前、会中、会后体验。所有互动均以活动 ID、入口 ID 和最小必要用户身份为边界，不将订单或身份详情暴露给公开页面。

## 任务

1. 发布自动化：草稿定时发布、发布前复用首页校验、旧版本归档、失败草稿保留给运营人员修正。
2. 入口分析：记录首页加载、入口点击、内容/资料打开；匿名事件不写用户身份，登录事件仅记录 `mp_user_id`。
3. 回放与反馈：回放继续作为受控内容入口，反馈按会议收集并支持后台查询、导出和关闭。
4. 展商互动：展商目录、联系方式和跳链沿用受控入口；预约/留资必须独立授权后才采集身份。
5. 运营驾驶舱：由服务端统一输出报名、签到、酒店、餐券、内容发布和入口事件的聚合指标，以及配置缺项和库存/核销异常。

## 验收

- 到期版本通过同一发布事务生效，任何时刻每个活动仅有一个已发布首页。
- 事件不接受任意用户 ID，服务端仅从登录态注入可选身份。
- 反馈、回放和展商入口遵守内容可见范围；未登录用户不能读取私有内容。
- 驾驶舱不返回手机号、房号、凭证或完整行为轨迹。
