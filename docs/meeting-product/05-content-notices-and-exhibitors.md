# 内容、通知与展商

## 1. 统一内容页

邀请函、会议通知、会议须知、组织机构、基本信息、学分须知、联系我们、会后考试说明等，默认都是“内容入口”而不是独立业务模块。它们共用一个移动端内容页和一套后台编辑能力，避免根据栏目名称重复建表和开发页面。

### 用户侧

- 顶部显示“首页 > 当前栏目”，并可打开当前活动的已发布入口树；
- 正文支持富文本、全宽长图、多图连续阅读、表格、电话和受控链接；
- 图片支持预览和长按保存；图片、正文和附件按配置排序；
- 页面只展示当前用户有权查看的内容，不可将个人消息、订单或房号写入公开内容页。

### Web 与服务端

- 内容实体至少包含：活动、标题、摘要、正文、封面、状态、排序、有效期、公开范围、附件与创建/更新时间；
- 入口仅引用内容 ID，不复制正文；同一内容可以被首页卡片、入口树和通知跳转复用；
- 富文本保存时清洗脚本、事件属性和危险 URL，渲染时限制标签与样式；
- 发布前校验正文或素材至少存在一项，失效内容、无权限内容和已删除附件不可作为有效目标。

## 2. 资料中心

### 用户侧

- 按会前资料、日程资料、会后资料分组；
- 支持 PDF、图片、视频、链接和文件；
- 可按日程、嘉宾和主题关联；
- 显示文件类型、大小、更新时间、有效期；
- 可配置下载是否需要登录或报名资格。

### 管理与服务端

- 复用现有活动文件能力并补齐资料元数据、公开范围、关联关系和下载记录；
- 文件上传后做类型、大小、病毒扫描策略和访问权限控制；
- 内容页富文本必须做 XSS 清洗，禁止脚本和事件属性。

附件应作为受控资料对象，不把文件 URL 直接散落在富文本中。后台配置文件名、类型、大小、有效期和下载权限；移动端按文件类型选择预览、下载或打开指引。微信内无法直接打开的文档应展示明确提示，不伪造下载成功。

## 3. 通知中心

通知分为全体通知、身份通知、日程变更、个人服务提醒。

- 支持标题、摘要、正文、优先级、有效期、跳转目标和接收范围；
- 会中首页展示最新 1～3 条，高优先级通知可弹窗；
- 用户可看到已读/未读；
- 日程、酒店、餐券等业务事件可触发站内消息，短信/微信为补充渠道；
- 必须支持频控、静默时段、去重和发送记录。

建议新增会议通知和用户已读记录；用户私有消息不得混入匿名首页接口。

## 4. 回放与反馈

- 日程结束后可自动露出回放；
- 支持场次评分、问题反馈和满意度问卷；
- 会后首页主推会议回顾、资料下载和意见反馈；
- 后台查看聚合趋势和导出时必须控制个人信息范围。

## 5. 展商服务

### 用户侧

- 按名称、展位、品类搜索展商；
- 详情展示品牌、产品服务、展位位置、公开资料；
- 一键导航至展位/展区；
- 支持收藏；
- 可选“预约洽谈/留下联系方式”，需由展商确认接收范围。

### Web 管理端

- 维护 Logo、封面、类别、展位、详情、外链和公开范围；
- 支持重点推荐进入首页运营位；
- 关联展位图，统计浏览、收藏、留资和预约；
- 展商联系人信息必须具有独立公开开关。

## 6. 验收

- 文件、通知和展商内容的可见范围正确；
- 高优先级通知不会因重复事件多次打扰同一用户；
- 从日程、嘉宾、首页运营位均能打开关联资料；
- 展商私密联系方式不会在未授权场景展示或导出。
- 运营人员可用同一内容编辑器发布邀请函、通知、须知等栏目；移动端内容页导航、正文长图和附件权限正确。
