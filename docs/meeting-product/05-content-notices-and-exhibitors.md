# 内容、通知与展商

## 1. 资料中心

### 用户侧

- 按会前资料、日程资料、会后资料分组；
- 支持 PDF、图片、视频、链接和文件；
- 可按日程、嘉宾和主题关联；
- 显示文件类型、大小、更新时间、有效期；
- 可配置下载是否需要登录或报名资格。

### 管理与服务端

- 复用现有活动文件能力并补齐资料元数据、公开范围、关联关系和下载记录；
- 文件上传后做类型、大小、病毒扫描策略和访问权限控制；
- 内容页富文本必须做 XSS 清洗，禁止脚本和事件属性。

## 2. 通知中心

通知分为全体通知、身份通知、日程变更、个人服务提醒。

- 支持标题、摘要、正文、优先级、有效期、跳转目标和接收范围；
- 会中首页展示最新 1～3 条，高优先级通知可弹窗；
- 用户可看到已读/未读；
- 日程、酒店、餐券等业务事件可触发站内消息，短信/微信为补充渠道；
- 必须支持频控、静默时段、去重和发送记录。

建议新增会议通知和用户已读记录；用户私有消息不得混入匿名首页接口。

## 3. 回放与反馈

- 日程结束后可自动露出回放；
- 支持场次评分、问题反馈和满意度问卷；
- 会后首页主推会议回顾、资料下载和意见反馈；
- 后台查看聚合趋势和导出时必须控制个人信息范围。

## 4. 展商服务

### 用户侧

- 按名称、展位、品类搜索展商；
- 详情展示品牌、产品服务、展位位置、公开资料；
- 一键导航至展位/展区；
- 支持收藏；
- 可选“预约洽谈/留下联系方式”，需由展商确认接收范围。

### Web 管理端

- 维护 Logo、封面、类别、展位、详情、外链和公开范围；
- 支持重点推荐进入首页运营位；
- 关联展位图，统计浏览、收藏、留资和预约；
- 展商联系人信息必须具有独立公开开关。

## 5. 验收

- 文件、通知和展商内容的可见范围正确；
- 高优先级通知不会因重复事件多次打扰同一用户；
- 从日程、嘉宾、首页运营位均能打开关联资料；
- 展商私密联系方式不会在未授权场景展示或导出。
