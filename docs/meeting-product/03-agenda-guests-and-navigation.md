# 日程、嘉宾与导航

## 1. 日程：今天该去哪

现有日程数据已具备日期、时间、主题、会场和嘉宾名称。目标是将其从静态列表升级为会中实时任务入口。

### 移动端

- 按日期、会场、主题、类型筛选；
- 时间轴展示，突出“正在进行”和“即将开始”；
- 日程详情：简介、嘉宾、会场、直播/回放、关联资料；
- 收藏日程并在开始前提醒；
- 首页“下一场”卡片可直接跳转会场导航；
- 变更后展示“已更新”和变更说明。

### Web 管理端

- 支持会场/时间轴方式编辑；
- 校验同会场时间冲突和嘉宾冲突；
- 配置状态：未开始、进行中、已结束、取消、变更；
- 配置详情、封面、直播、回放、资料关联；
- 变更时可通知收藏者、指定身份或全体参会者；
- 提供“今日议程检查”报告。

### 服务端扩展

建议在 `yc_schedule` 或关联表中增加 `schedule_status`、详情内容、封面、直播/回放地址、变更说明；新增用户收藏、日程变更记录和资料关联。

## 2. 嘉宾：可信的内容入口

### 移动端

- 嘉宾头像、姓名、机构、职务、主题标签；
- 搜索和按主题/机构筛选；
- 详情展示简介、相关场次和资料；
- 可从详情直达关联日程；
- 可收藏嘉宾和关联场次。

### Web 管理端

- 结构化维护简介、头像、标签、公开范围；
- 嘉宾与日程多对多关联；
- 重点嘉宾可进入首页运营卡片；
- 修改资料时提示受影响日程和首页内容。

私人手机号等敏感联系方式默认不公开。

## 3. 会场与 POI 导航

### 产品模型

- 场地：承载日程的会场信息；
- POI：注册处、餐厅、接驳点、医疗点、服务台等可导航点。

二者需要分离管理并可相互关联。

### 移动端

- 首页显示“下一场在哪里”；
- 会场详情显示地址、楼层、直播状态、服务电话和地图；
- 从日程详情一键发起路线导航；
- 支持酒店、注册处、主/分会场、餐厅、接驳点、服务台等 POI；
- 无经纬度时不展示无效导航按钮；
- 导航入口可先打开站内会场说明，再交由用户选择高德、百度或系统地图；不在前端拼接不受控地图 URL；
- 条件成熟后可增加会场平面图和室内导引。

### Web 与服务端

- POI 必填分类、坐标、地址、服务时段和排序；
- 首页或内容页的地图入口只引用 POI/会场 ID，由服务端根据有效坐标生成可用导航能力；
- 保存时校验经纬度；
- 会场支持开放、拥挤、关闭等现场状态及临时公告；
- 删除会场前校验关联日程，禁止产生悬空引用；
- 现有 `yc_venue`、`yc_activity_nav` 可复用，先补直连体验和分类字段。

## 4. 验收

- 当前/下一场计算与会议时间一致；
- 日程变更刷新后所有相关页面一致；
- 用户可从任意日程直达关联会场导航；
- 嘉宾、会场和日程之间均可正向跳转；
- 没有有效数据的入口由服务端隐藏或给出明确空状态。
