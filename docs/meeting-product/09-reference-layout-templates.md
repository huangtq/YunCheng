# 参考站首页版式模板

模板是“整页区块的排列规则”，不是会议功能清单，也不是主题色预设。每个会议选择一个模板后，只替换本场的主视觉、入口图片、标题、目标和页脚信息；移动端使用同一份已发布 `page_json` 渲染。

## 首批模板

| 模板 | 参考会议 | 固定结构 | 每场可配置 |
| --- | --- | --- | --- |
| 主视觉图片菜单 | `38736`、`38335`、`30995`、`24669` | 主视觉 -> 倒计时 -> 连续图片菜单 -> 页脚 | 主视觉、主题色、倒计时开关、入口图、入口目标、页脚 |
| 分区图片菜单 | `38760` | 主视觉 -> 倒计时 -> 快捷图片区 -> 重点图片区 -> 页脚 | 主视觉、每个分区的入口图/目标/顺序、页脚 |
| 主视觉图标导航 | `29690` | 主视觉 -> 翻牌倒计时 -> 三列图标菜单 -> 页脚 | 主视觉、主题色、入口图标、入口目标、页脚 |
| 整图热点海报 | `36428` | 单张长海报 -> 透明热点 | 海报、热点标题、矩形坐标、热点目标 |

## 配置原则

- 入口目标一律选择受控对象：原生模块、已发布内容或合法 `https` 外链；标题不决定行为。
- 图片菜单模板中的入口图使用横向 2:1 素材；图标模板使用方形图标；热点模板使用与视觉稿相同的长图。
- 模板切换只生成草稿结构，必须保存、预览和发布后才影响用户。
- 新增参考站时，先判断能否复用现有模板；只有首屏、区块顺序、分区或卡片比例不同才新增模板。图片、主题色和入口目标不同不构成新模板；不为单一会议在 H5 写分支。

## 当前实现

Web 的 [九宫格配置](../../web/src/views/meeting/grid/index.vue) 是会议页唯一配置入口：模板、视觉、九宫格入口、草稿和发布均在同一页面完成。首页版本表只保存该页面生成的 `page_json`；移动端从统一首页协议读取 `templateKey`、`layout` 和 `entryTree`。
