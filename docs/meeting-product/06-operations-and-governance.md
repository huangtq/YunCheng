# 运营工作台、数据治理与权限

## 1. 会议运营驾驶舱

### 会前检查

- 基础信息、封面、时间、地点是否完整；
- 首页是否已发布，二维码和分享链接是否有效；
- 是否至少存在可用报名通道；
- 表单、隐私说明、日程、会场是否完整且无冲突；
- 首页可见模块是否有数据；
- 酒店、餐券、导航、资料是否按需配置。

### 会中看板

- 今日报名、到场、签到；
- 当前/下一场日程；
- 酒店未确认、库存风险；
- 餐券待核销、异常核销；
- 最新通知和首页当前版本；
- 场次变更未通知、入口指向空数据等高风险提示。

### 会后收尾

- 回放和资料发布情况；
- 反馈收集；
- 签到、餐券、酒店归档；
- 首页自动切换会后模式；
- 隐私数据保留与清理计划。

## 2. 数据质量与依赖管理

系统在操作前应提示影响范围，而不是仅允许/禁止：

| 操作 | 必须提示的影响 |
| --- | --- |
| 关闭报名通道 | 新用户不可报名，已报名用户不受影响 |
| 修改日程时间 | 影响首页下一场和收藏提醒，可选择通知 |
| 删除会场 | 展示关联日程数量，阻止悬空引用 |
| 下架酒店 | 展示待确认订单数量 |
| 停用餐券 | 未使用券将不可核销 |
| 下架首页入口 | 已发布版本可能仍引用，需发布新版本 |
| 下架内容或附件 | 展示引用该内容的入口、首页运营位和通知，阻止产生失效链接 |
| 修改地图 POI | 展示关联会场、日程和导航入口，提示坐标变更影响 |

## 3. 权限模型

除 CRUD 外，增加业务权限：

- 首页编辑、发布、回滚；
- 报名审核、订单导出、现场核验；
- 日程变更和通知；
- 酒店订单处理、分房；
- 餐券发放、核销、核销撤销；
- 通知发布、数据看板查看；
- 敏感数据查看和导出。

内容编辑权限不自动包含首页发布权限；能维护富文本不等于能把内容推送给全体参会者。外链、附件下载权限和地图 POI 修改同样应纳入活动级审计。

能编辑会议不等于能导出手机号、查看房号或撤销核销。所有敏感操作需审计。

## 4. 事件和指标

关键事件：报名提交/审核、日程变更、签到、酒店确认分房、餐券开放核销、高优先级通知、资料回放上线。

关键指标：首页加载和点击、报名转化与审核时长、日程收藏和提醒、签到率、餐券核销率、酒店确认率、资料下载/回放率、发布失败原因。

数据采集区分匿名与登录行为，遵循最小化采集和可配置保留期。

## 5. 验收

- 运营人员能在一个页面发现会前缺项和会中风险；
- 高敏感数据和操作均受角色控制并留下审计；
- 数据质量提示能定位到具体对象和影响范围；
- 指标口径由服务端统一，前端不自行重复计算。
