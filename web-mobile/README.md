# YunCheng Mobile

基于 RuoYi-App（vue3 分支）的移动端，uni-app（Vue3 + Pinia），一套代码可编译到 App、小程序、H5。

## 技术栈

- uni-app
- Vue 3 + Pinia
- uni-ui

## 已有能力

登录、工作台、个人中心、编辑资料、头像修改、密码修改、常见问题、关于我们等基础功能。

## 本地运行

本项目面向 **HBuilderX**：

1. 用 HBuilderX 打开本目录
2. 修改 `config.js` 中的 `baseUrl`，指向本地或远程后端
3. 菜单「运行」→ 运行到浏览器 / 模拟器 / 小程序

请先启动 `server` 后端后再访问。
